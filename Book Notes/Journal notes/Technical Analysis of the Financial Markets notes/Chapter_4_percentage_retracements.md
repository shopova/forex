Section focus:

## Core Idea

- Retracement depth helps estimate whether a move is still a correction or is becoming something more serious.
- Classic reference zones help organize expectation, even if they are not exact.

## What This Changes For Me

- I should use retracement depth as context, not as an entry trigger by itself.
- Very deep pullbacks deserve more skepticism than shallow, orderly ones.

## Rule Extracted

- `Retracement depth is a quality clue: the deeper and more aggressive the pullback, the more I should question pure continuation.`

## Practical Forex Translation

- This fits your pullback-quality work directly. Retracement can help judge whether a retest still supports continuation or is already damaging the trend structure.
