# Trade Coaching Log Template

Use this file for individual trade submissions in this thread.

Purpose:

- keep `Daily Journal.md` focused on broad market alignment
- keep trade-by-trade coaching structured and reviewable
- separate `replay study`, `demo execution`, and `live-model validation`
- capture decision quality, not only outcome

This template is built for your actual `2026` workflow:

- primary goal: explore price movement in replay
- secondary goal: trade demo when possible
- limited discretionary time because of the baby
- current strategy baseline: `Daily / 4H / 30m`

## How To Use

- copy one trade block per trade
- fill the pre-trade sections before entry when possible
- update management and result sections after the trade closes
- if a trade is skipped, keep the block and mark it `Skipped`
- attach screenshots separately in chat when you want coaching

## What To Send Me In Chat

For coaching, send:

- this filled trade block
- `Daily`, `4H`, and `30m` screenshots
- marked key levels
- any relevant news context

## Minimum Standard

If you are in a hurry, at minimum send me:

- pair
- date and time
- replay or demo
- `Daily`, `4H`, `30m` screenshots
- HTF alignment
- key level
- level event type
- context type
- trigger type
- entry, stop, target
- projected `R`
- why it is valid
- why it could fail
- whether it is `Fully valid`, `Partial fit`, or `Pattern study only`

That is the minimum needed for serious coaching.
