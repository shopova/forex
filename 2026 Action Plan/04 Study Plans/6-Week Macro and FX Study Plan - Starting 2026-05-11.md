# 6-Week Macro and FX Study Plan

Start date: `2026-05-11`

This plan is built for your actual trading model:

- `Daily` for macro structure and major levels
- `4H` for market condition and decision zones
- `30m` for execution and trigger confirmation
- no trade if confirmation does not produce a clean setup
- default setup-quality gate requires projected reward-to-risk `>= 2R`

This is not an academic economics course.

The purpose is to make you better at answering:

- what matters in the macro backdrop right now
- whether central-bank expectations support or weaken your thesis
- whether a move is broad `USD` repricing or only local chart noise
- whether your `30m` trigger is occurring at a real higher-time-frame location

## Core Weekly Structure

Use this default structure each week:

- `Monday`: macro foundation reading + `Daily` map
- `Tuesday`: policy / central-bank reading + `4H` context work
- `Wednesday`: rates / cross-asset context + `30m` trigger study
- `Thursday`: applied chart work and scenario writing
- `Friday`: review and note consolidation
- `Saturday`: replay / historical chart study
- `Sunday`: light scan or full rest

Default session length:

- `30-45 min` reading
- `45-60 min` chart work
- `10-20 min` written notes

Pairs:

- `EURUSD`
- `GBPUSD`
- `USDJPY`
- `USDCAD`

## Core Rules To Carry Through All 6 Weeks

- do not study macro as general knowledge only
- convert every macro concept into trading relevance
- judge every setup through `Daily -> 4H -> 30m`
- no trigger is valid without level quality and structural invalidation
- if confirmation destroys location or `R:R`, skip
- if the move is broad macro-driven `USD` repricing, require stronger evidence before fading it
