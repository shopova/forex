## Suggested Use

- use this during the `09:45-10:20` main analysis block
- keep the morning version concise
- add the end-of-day review later in the day
- if no trade occurs, still fill the review section

## Minimum Standard

If the template is filled well, it should answer:

- what matters today
- which pair has the cleanest context
- what a valid trigger would need to look like
- whether the setup still meets the `>= 2R` standard
- whether the best decision is actually `no trade`
