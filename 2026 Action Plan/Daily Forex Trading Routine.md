# Daily Forex Trading Routine

## Purpose

Provide a fixed daily operating routine for the current rebuild phase.

This routine is designed for:

- part-time trading
- study-heavy strategy development
- structured chart analysis and backtesting
- limited discretionary windows during the day

It is not designed for all-day chart watching.

## Operating Principle

Your main job for the current phase is:

1. build judgment
2. build a repeatable process
3. avoid emotional and low-quality trades

Profit is secondary to:

- rule clarity
- execution quality
- stable behavior

## Current Trading Windows

Use these Bulgarian-time windows:

- primary decision window: `10:30-12:00`
- secondary management / preplanned execution window: `15:00-16:00`

Outside these windows:

- alerts are allowed
- chart monitoring is allowed
- discretionary entries are not allowed

## Pair Scope

Primary pairs:

- `EURUSD`
- `GBPUSD`
- `USDJPY`

Secondary pair:

- `USDCAD` only if it is specifically relevant to the `15:00-16:00` New York overlap

Do not expand the watchlist by mood.

## Timeframe Structure

- `Daily`: bias and major levels
- `4H`: condition, structure, and zone quality
- `30m`: execution and trigger chart

`5m` is not part of the default workflow.

## Allowed Trade Contexts

Only two trade contexts are allowed:

1. continuation from a meaningful level after a healthy pullback
2. liquidity sweep reversal from a meaningful level

No trade if price is:

- mid-range
- overlapping and messy
- structurally unclear
- too close to major news

## Daily Routine

### 1. Main Analysis (`09:45-10:20`)

This is the only full market analysis of the day.

- check sleep, focus, and emotional state
- check high-impact news for the day
- mark `Daily` bias on approved pairs
- mark `4H` structure:
  - trend
  - range
  - transition
- draw key levels and zones
- write one continuation scenario and one sweep / reversal scenario per pair
- set alerts at levels of interest

If you cannot describe the chart clearly in one or two sentences, the pair is not ready.

### 2. Pre-Execution Update (`10:25-10:30`)

Keep this short.

Use it only to confirm:

- what changed since the main analysis
- whether price is now closer to a planned level
- whether a pair is still `No trade`, now a `Candidate`, or now a `Valid setup`

Do not start a fresh broad analysis here.

### 3. Primary Decision Window (`10:30-12:00`)

This is the main discretionary session.

- focus only on pre-marked pairs
- wait for price to reach planned levels
- use only `30m` trigger logic
- enter only if structure, location, invalidation, and reward all make sense
- prefer stop orders over reactive market entries

Before any order, confirm:

1. pair is approved
2. level was marked in advance
3. trade fits one of the two allowed contexts
4. trigger is clean
5. structural invalidation is obvious
6. projected reward is at least `2R`
7. total risk is within plan

If any item fails:

- no trade

### 4. Secondary Session Update (`14:40-14:55`)

This is a narrow update, not a second full analysis block.

Use it for:

- checking what changed since the morning
- whether a key level broke, held, or was reclaimed
- updating existing scenarios only
- deciding whether the `15:00-16:00` window has a preplanned opportunity or only observation value

If no major level was reached or broken, this update should usually take less than `15` minutes.

### 5. Secondary Window (`15:00-16:00`)

This is not a second full discretionary session.

Use it only for:

- preplanned execution at already marked levels
- order management
- canceling stale setups
- observing New York behavior for journaling and study

Do not perform a fresh broad analysis during this window.

### 6. Study Block (`90-180 min`)

This is mandatory during the current six-month phase.

Default split:

- `60-120 min` reading and notes
- `45-60 min` chart annotation or replay
- `15-30 min` extracting one practical rule or checklist update

Use the current study framework:

- `Book Notes/Guidelines/12_week_edge_curriculum_2026.md`
- `Book Notes/Guidelines/art_and_science_foundation_plan_2026.md`

Your study output for the day should produce at least one of these:

- a concept note
- a chart example
- a rule candidate
- a checklist improvement

### 7. Post-Session Review And Journal (`16:10-16:25`)

If this exact time is not available, do the review later in the day in one focused `15-20 min` block.

Record:

- pair
- session
- market condition
- planned scenario
- actual trigger
- entry, stop, target
- planned `R`
- result in `R`
- whether the trade matched the plan
- whether you would take it again
- one lesson

If there was no trade, journal:

- what you watched
- what you rejected
- whether the rejection was correct

## Analysis Rule

- one full analysis per day
- one short pre-execution update
- one short afternoon update
- one end-of-day review

This prevents over-analysis while still keeping you connected to market changes.

## Daily Risk and Activity Limits

Current default limits:

- risk per trade: `0.25%`
- maximum `2` trades per day
- maximum `1` open position at a time
- maximum daily loss: `0.50%`

If daily loss is hit:

- stop trading for the day
- do journal review only

## News Rules

- no new discretionary trades within `60` minutes before major scheduled news
- no new discretionary trades within `30` minutes after major scheduled news unless structure is very clear and already planned
- if already in a trade, manage according to the plan; do not improvise because of fear

## Weekly Structure

Use this weekly rhythm:

- `4` study-heavy days
- `2` chart-analysis / backtesting-heavy days
- `1` weekly review day

Weekly review must include:

- trades taken
- trades skipped correctly
- rule violations
- strongest setup
- weakest setup
- one change to keep
- one mistake to reduce next week

## Non-Negotiables

- no phone entries
- no impulse trades
- no widening stops
- no revenge trading
- no adding to losers
- no trade because of boredom
- no breaking the session rules because of missed opportunities

## What Counts As A Good Day

A good day is:

- well prepared
- well filtered
- well documented

A no-trade day can still be a successful day.
