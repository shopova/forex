# 90 Day Live Rebuild Plan

This plan is built around the latest recorded MetaTrader balance in your statements:

- starting live rebuild balance: `EUR 387.50`

The purpose of this plan is not fast growth.

The purpose is to rebuild:

- discipline
- emotional stability
- positive expectancy
- trust in your own execution

This is a recovery plan, not an income plan.

## 1. Starting Point

At `EUR 387.50`, capital protection matters more than return speed.

Your first objective is:

- survive `90` days with controlled behavior

Not:

- make the account back quickly
- prove yourself through aggression
- prepare for FTMO by forcing results

## 2. Core Rules for the Full 90 Days

These rules apply for the entire rebuild period.

- no phone entries
- desktop only
- one trading session only
- maximum `1` open position at a time
- maximum `2` trades per day
- maximum `6` trades per week
- no same-pair re-entry unless a completely new setup forms
- no adding to losers
- no widening stops
- no trading during emotional urgency

Trade only if all of these exist:

1. `Daily` bias
2. clean `4H` impulse
3. healthy correction
4. valid `1H` trigger

If the first three are not present, there is no trade.

## 3. Risk Framework

### Main Risk Limit

Use:

- normal risk per trade: `0.25%`

At `EUR 387.50`, that is:

- `EUR 0.97` maximum risk per trade

### Daily and Weekly Limits

Use:

- daily max loss: `0.50%`
- weekly max loss: `1.50%`

At `EUR 387.50`, that is:

- daily stop: `EUR 1.94`
- weekly stop: `EUR 5.81`

If either limit is hit:

- stop trading immediately
- journal the day
- resume only on the next valid session

### Important Practical Constraint

At this account size, broker lot-step limits may make true `0.25%` risk impossible on some setups.

If your minimum tradable size risks more than `EUR 0.97`, you must:

- skip the trade, or
- use demo for that setup

Do not force a trade because the broker minimum size is too large.

Check:

### Setup Scope

### Process Goal

## 8. Daily Routine for the 90 Days

Use the same routine every trading day.

### Pre-Session (20-30 min)

- check emotional state
- check high-impact news
- mark `Daily` bias
- identify the last clean `4H` impulse
- decide whether current price is in healthy correction
- set alerts

If the chart is unclear:

- no trade

### Execution Window

- trade only the planned session
- use stop orders only
- enter only after the setup is complete
- size the trade before sending the order

### Post-Session (10-15 min)

Journal:

- setup type
- whether all rules were met
- emotion before entry
- emotion after exit
- whether you would take the same trade again

## 9. Weekly Review Structure

At the end of each week, record:

- number of trades
- win rate
- average win
- average loss
- net `R`
- largest loss
- rule violations
- emotional triggers

Then assign one label:

- `clean week`
- `sloppy week`
- `stop-and-reset week`

If it is a sloppy or stop-and-reset week:

- next week uses lower activity, not higher activity

## 10. What to Do After a Losing Trade

Use this exact sequence:

1. Stop.
2. Mark whether the loss was planned or unplanned.
3. If planned and valid, accept it.
4. If unplanned or oversized, stop for the day.
5. No immediate re-entry from frustration.

Your goal is to normalize small planned losses.

That is how trust in execution is rebuilt.

## 11. What Counts as Failure During the Rebuild

The rebuild is failing if you:

- trade from the phone
- exceed planned risk
- take more than `2` trades in a day
- revenge trade after a loss
- enter without `4H` structure
- widen a stop

One green day does not erase this.

Behavior matters more than outcome.

## 12. What Counts as Success at Day 90

You are ready to progress only if most of these are true:

- at least `30` total trades completed
- no risk-rule violations in the final `30` days
- no single outsized loss
- positive expectancy
- average loss is controlled
- no phone entries
- you can accept no-trade days without pressure

If these are not true, repeat the plan instead of escalating.
